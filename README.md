## 🌟 Why Use elevate?

Most companies have special security tools like Azure and Microsoft Entra. If you're an administrator, a developer, or an IT person, you probably need access to them sometimes to do your job.

But having permanent access to these powerful tools is a security risk. If your account is ever compromised, a bad actor could do a lot of damage.

**elevate solves this by giving you access *only* when you need it.** It's like a security guard who lets you into the server room only when you show your badge for a specific reason. This is called "Just-in-Time Access," and it's a best practice for modern security.

Here are a few common issues and how to fix them:
